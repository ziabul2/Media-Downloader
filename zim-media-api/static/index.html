The file stays where it is.

ZIM reads a public media page, names the real formats, and gives your device a short-lived route to the original host. Nothing is kept as a library.

Source

Development attaches a local owner key. It is not a production credential.

Delivery order

  1. DirectThe source URL, only after the file, codecs, and headers are checked.
  2. RedirectA ZIM ticket that answers 302 and stores nothing.
  3. ProxyOff until it is explicitly enabled. Not a way around locks.

What this will not do

  • Bypass DRM, paywalls, private accounts, or geographic locks.
  • Rename M4A or WebM to MP3. Conversion is reported, not pretended.
  • Call a silent video a complete MP4, or merge split streams on the server.
  • Keep a media library. Tickets expire. The host sends the bytes.
